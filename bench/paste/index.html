How quickly can we check a paste?

This experiment compares local detection rules, a short Gemini Nano sensitivity check, and the app’s full name and topic scan. All model processing stays on this device.

The suite uses 17 fixed fictional samples, including clean text, ambiguous text, and sensitive information at the end of long passages. A fast result is not proof that no sensitive data remains.

The Nano check visits every overlapping 500-word chunk. It records the first warning separately from completion. Long samples use repeated neutral editing instructions to control length; they do not represent every document style.
